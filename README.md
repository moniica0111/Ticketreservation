# Multi-Tenant Event & Ticket Reservation System

A web-based event management and ticket reservation platform that enables administrators to manage organizers, organizers to create and manage events, and attendees to reserve tickets.

## Live Application

- **Frontend:** [https://ticket-reservation-six.vercel.app](https://ticket-reservation-six.vercel.app)
- **Backend API:** [https://ticketreservation-1ezt.onrender.com](https://ticketreservation-1ezt.onrender.com)

## Project Overview

The Multi-Tenant Event & Ticket Reservation System provides a centralized platform for event creation, ticket management, and reservation processing. The application supports role-based access for administrators, organizers, and attendees.

## Features

- Event creation and management
- Ticket categories, pricing, and quantity management
- Event browsing and ticket reservation
- Organizer dashboard with event statistics
- Admin dashboard for organizer and event management
- Checkout interface with mock payment processing
- Backend API for application operations

## User Roles

### Administrator
- Manage organizers
- Approve or suspend organizers
- Manage events
- View platform statistics

### Organizer
- Create and manage events
- Configure ticket categories and pricing
- Manage ticket availability
- View event analytics

### Attendee
- Browse available events
- View event details
- Select ticket quantities
- Reserve tickets and proceed to checkout
